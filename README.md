# Сапёр

Классический сапёр в браузере. Один файл `index.html`, без зависимостей.

- ЛКМ — открыть клетку / «аккорд» по цифре
- ПКМ по закрытой клетке — флаг
- ПКМ по цифре — автоматически ставит флаги на соседей, которые точно мины

## Хостинг на GitHub Pages
1. Создай репозиторий, положи `index.html` в корень.
2. Settings → Pages → Source: `main` / `(root)` → Save.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.
