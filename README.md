# Saper

Сапёр в браузере. Всё в одном файле `index.html`, без сборки и зависимостей.

Играть: https://kavdas.github.io/Saper/

## Управление

Мышь:
- левая кнопка — открыть клетку; по цифре — открыть соседей, если вокруг уже стоит столько флагов, какая цифра
- правая кнопка по закрытой клетке — флаг
- правая кнопка по цифре — флаги на соседей, которые точно мины

Телефон: тап — открыть, долгое нажатие — флаг. Кнопка «Флаг» меняет это местами.

## Режимы

- Поле: 9×9 (10 мин), 16×16 (40), 30×16 (99).
- На время: обратный отсчёт, 2 / 7 / 18 минут в зависимости от поля.
- Безопасный ход: кнопка с ограниченным числом зарядов. Нажимаешь её, потом цифру — откроются соседи, про которые точно известно, что мин там нет.
- Старт: первый клик открывает либо пустую область, либо только одну клетку.

## Запуск у себя

Достаточно открыть `index.html` в браузере. Для GitHub Pages: Settings → Pages → ветка `main`, папка root.
