ЛКМ — открыть клетку; по цифре — открыть соседей, если флагов столько же.
ПКМ по закрытой — флаг. ПКМ по цифре — флаги на соседей, которые точно мины.
🛡 Безопасный ход — нажми кнопку, затем цифру: откроются соседи, которые точно безопасны. Ходов ограниченное число, тратится только при успехе.
На телефоне: долгое нажатие = ПКМ.
